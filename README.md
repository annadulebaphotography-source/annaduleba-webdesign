# Anna Duleba Digital Atelier

Static premium website for `annaduleba-webdesign.de`.

## Pages

- Atelier / homepage
- Webdesign offer
- Website strategy
- Branding gallery
- About Anna
- Contact

## Stack

- Static HTML, CSS and vanilla JavaScript
- Firebase Auth and Firestore for the lightweight CMS
- Cloudinary for image uploads
- Netlify-ready static hosting

## Local Preview

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Open `http://127.0.0.1:4173/index.html`.
